## 01 / ABOUT

I completed my BCA in 2026. What keeps me interested in software is the moment logic has to become something a person can actually use: a screen, a flow, a small interaction that feels right.

So I work on both sides of it. The code that makes a product run, and the design that decides how it feels. I'll build the API, then open Figma and argue with myself about spacing.

```
LOGIC        →  how it works
TECHNOLOGY   →  what it runs on
DESIGN       →  how it feels
CREATIVITY   →  why it feels different
```
